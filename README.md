# ✦ NOIR VAULT - Luxury Fragrance Database & Real Filter Engine

Plataforma moderna de alta perfumaria com catálogo completo de 300 perfumes importados e nacionais com sistema de filtragem multi-facetada em tempo real, busca sem distinção de acentos e pirâmides olfativas completas.

---

## 💎 Funcionalidades
- **300 Perfumes Catalogados:** Nicho (Creed, Parfums de Marly, Xerjoff, MFK, Kilian, Initio, Nishane, Amouage, Tom Ford Private) e Designers de Prestígio (Dior, Chanel, YSL, Armani, JPG, Paco Rabanne, Givenchy, Prada, Versace, O Boticário, Natura).
- **Filtros 100% Funcionais em Tempo Real:** Filtragem cruzada por Gênero, Família Olfativa, Ocasião/Clima e Intensidade/Fixação.
- **Busca Insensível a Acentos:** Digite "sauvage", "citrico", "baunilha", "cha", "cafe", "maca" ou "elysee" e encontre instantaneamente.
- **Pirâmides Olfativas Reais:** Modal com Topo, Coração e Fundo para cada perfume.
- **Lista de Favoritos:** Salve perfumes favoritos persistidos no `localStorage`.

---

## 🚀 Como Executar Localmente
Basta abrir o arquivo `index.html` em qualquer navegador web.

---

## 🌐 Como Publicar no GitHub Pages
1. Crie um repositório no seu GitHub (ex: `noir-perfumes`).
2. Faça o upload dos 4 arquivos (`index.html`, `style.css`, `perfumes.js`, `app.js`).
3. Vá em **Settings** > **Pages** e selecione a branch `main`.
4. Salve e o site estará no ar gratuitamente com link HTTPS.
